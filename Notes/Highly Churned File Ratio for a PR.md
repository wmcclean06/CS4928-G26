## Highly Churned File Ratio for a PR 
Highly Churned File Ratio for a PR= Number of highly churned files in the PR / Number of total files in the PR

For a file to be considered Highly churned it must have a code churn ratio of 5+

## Code Churn Ratio for a file
The method of calculating Code churn is 
Code Churn Ratio for a file = Cumulatively changed number of lines of code / Total number of current lines of code

The Cumulative part of this is over the files total lifetime in the repository.
As such a code churn ratio of 5+ means that this file has been fully rewritten about five times over its lifetime in the repository
